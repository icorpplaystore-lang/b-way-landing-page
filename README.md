# B-Way Landing Page

Unified website for **Technology Solutions** and **Workforce & Business Solutions**.

Built with **Next.js**, **Tailwind CSS**, and **Lucide** icons.

## Core message

> Technology. People. Business.  
> Building digital solutions, connecting people and helping businesses move forward.

## Main navigation

- `/` Home
- `/services` Services (Technology / Workforce tabs)
- `/industries` Sectors We Serve
- `/portfolio` Portfolio
- `/about` About Us
- `/insights` Insights
- `/contact` Contact Us

## Audience & trust pages

- `/employers` For Employers
- `/job-seekers` For Job Seekers
- `/compliance` Compliance & Regulatory Excellence

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

```
src/
  app/                 # Routes
  components/
    layout/            # Navbar, Footer
    shared/            # CTA, Testimonials
    ui/                # Shared UI primitives
  sections/            # Page section components
  lib/
    constants.ts       # Nav, service trees, footer
    data/site-content.ts
```
